# Nimbus Cashier for iOS

In-app subscriptions for iOS, iPadOS, macOS, tvOS, watchOS and visionOS, backed by [Nimbus Cashier](https://nimbusgo.space/docs/cashier-cloud). Your app buys through StoreKit 2; Cashier verifies every transaction with Apple, keeps it current through renewals, refunds and billing problems, and answers one question: *is this user entitled to premium?*

Paywalls you design in the Cashier console open natively with `PaywallView`.

**Requirements:** iOS 15 / macOS 12 / tvOS 15 / watchOS 8 / visionOS 1, Xcode 15.3+ (Swift 5.10).

## Install

Swift Package Manager — in Xcode, **File › Add Package Dependencies…** and enter:

```
https://github.com/CodeSyncr/cashier-ios.git
```

or in `Package.swift`:

```swift
dependencies: [
    .package(url: "https://github.com/CodeSyncr/cashier-ios.git", from: "1.0.0"),
],
targets: [
    .target(name: "App", dependencies: [.product(name: "NimbusCashier", package: "cashier-ios")]),
]
```

CocoaPods (iOS 15+ / macOS 12+) — in your `Podfile`:

```ruby
pod 'NimbusCashier', :git => 'https://github.com/CodeSyncr/cashier-ios.git', :tag => '1.1.0'
```

(`pod 'NimbusCashier', '~> 1.1'` once the pod is on the CocoaPods trunk.) The React Native SDK, `@codesyncr/cashier-react-native`, installs it this way.

## Use

```swift
import NimbusCashier

// Once, at launch — the PUBLIC key from your Cashier app's Settings & keys.
Cashier.configure(apiKey: "cshr_pub_…")

// After your own sign-in:
try await Cashier.shared.logIn(user.id)

// Gate a feature:
let info = try await Cashier.shared.customerInfo()
if info.isEntitled(to: "premium") { /* unlock */ }

// Buy a package from the current offering:
let offering = try await Cashier.shared.offerings().current
let result = try await Cashier.shared.purchase(offering!.availablePackages[0])

// Restore:
try await Cashier.shared.restorePurchases()
```

Show the paywall you designed in the console:

```swift
ContentView()
    .presentPaywallIfNeeded(requiredEntitlement: "premium")
```

Or embed it yourself, with options:

```swift
PaywallView(
    offering: nil,                      // nil: the current offering (experiment variant included)
    onPurchaseCompleted: { info in … },
    onRestoreCompleted: { info in … },
    onDismiss: { … },                   // nil: dismisses the presenting sheet
    locale: Locale(identifier: "es"),   // nil: Locale.preferredLanguages.first
    onAnswer: { answer in               // Feedback / Marketing Consent screens
        if answer.screenID == "consent", answer.answer == "yes" { requestNotifications() }
    }
)

// The gate takes the same two options:
ContentView()
    .presentPaywallIfNeeded(requiredEntitlement: "premium", locale: nil, onAnswer: { answer in … })
```

- **Languages.** Paywalls translated in the console are drawn in the language best matching `locale`: an exact match (`pt-BR`), else the same language (`pt-BR` → `pt`), else the default texts. A request in the paywall's default language without an exact match keeps the default texts. `{{price}}` and the other variables work inside translations. To render a `PaywallContent` yourself in a language, use `doc.localized(for: Locale?)` or `doc.localized(to: "pt-BR")`.
- **Analytics.** `PaywallView` reports a `view` when the paywall is first shown and a `close` when it is dismissed without a purchase (fire-and-forget; never blocks the UI). Preview-token drafts report nothing.
- **Answers.** A button with an `answer` calls `onAnswer(PaywallAnswer(screenID:question:answer:))`, records it with Cashier, then does its normal action. `question` is the screen's question, else its name.
- **Experiments.** `offerings()` sends the app user id so Cashier can assign A/B tests. `Offerings.experiment` (and the current offering's `experiment`) is `PaywallExperiment(id:variant:)` while the user is enrolled; `Offering.paywallID` is the published paywall's id.

The full guide — console setup, App Store Connect, testing and going live — is at **https://nimbusgo.space/docs/cashier-ios**.

## Develop

```sh
swift test
```

`Tests/NimbusCashierTests/Fixtures/paywalls.json` is generated by the Cashier server's schema tests, so the renderer is tested against every document the editor can save. Regenerate it from the server repo:

```sh
PAYWALL_FIXTURES=$PWD/../cashier-ios/Tests/NimbusCashierTests/Fixtures/paywalls.json go test ./app/paywall -run Fixtures
```

`Sources/NimbusCashier/Resources/paywall-art.json` (the built-in paywall illustrations) is shared with the web SDK; update both together.

## Release

1. Update `Cashier.version` in `Sources/NimbusCashier/Cashier.swift` and `CHANGELOG.md`.
2. Tag the commit with the version (`git tag 1.0.1 && git push --tags`). Swift Package Manager resolves versions from tags; nothing else to publish.
